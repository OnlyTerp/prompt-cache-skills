## Status: default Desktop Code verified

The earlier “closed source, can't verify” framing was too weak. A clean
macOS Claude Desktop Code run verified that the default Desktop Code
surface uses prompt caching.

The clean default check found:

- Claude Desktop app bundle: `com.anthropic.claudefordesktop` `1.9255.2`.
- Embedded Claude Code launched by Desktop: `2.1.149` under the app's
  user data directory, invoked with stream-json/verbose output.
- No standalone `claude` binary on `PATH`; the observed surface was
  Desktop Code, not a separate npm/Homebrew CLI install.
- No `ENABLE_PROMPT_CACHING_1H`, `ANTHROPIC_CUSTOM_HEADERS`, or proxy
  variables in the session environment.
- `ANTHROPIC_BASE_URL` was present, but in this clean Desktop Code run
  it was the normal Desktop host-brokered path for the embedded Code
  runtime, not evidence of a user-installed gateway or enterprise custom
  provider.
- Config/log grep did not find active `custom-3p`, `inferenceGateway`,
  enterprise config, or prompt-caching override. Matches were only in
  prior tool-output text captured in logs.

These counters are provider usage fields, not prompt text, auth headers,

`cache_creation_input_tokens` proves cache entries are being written;
non-zero `cache_read_input_tokens` proves warm requests are hitting the
cache.

## How good is it?

The verifier computed session-level economics from those same counters:

- Cache hit ratio: 85.6%.
- Reuse factor: 5.95x.
- Fresh input ratio: approximately 0.01%.
- Estimated input-side cost versus no-cache: about 37%, or roughly 63%
  input-side savings.

Those are strong prompt-cache numbers for an agentic desktop-code
session. Output tokens are not affected by prompt caching and are not
included in the input-side savings estimate.

## Scope and caveats

This audit now verifies the default **Claude Desktop Code** path. It does
not separately prove every Anthropic surface:

- Standalone `claude` CLI installed via npm/Homebrew was not tested in
  the clean Mac run because no standalone CLI was on `PATH`.
- The non-Code general desktop chat surface was not separately tested.
- Cowork should be treated as a separate desktop surface unless a clean
  stock Cowork run is captured. A configured Cowork/local-gateway setup
  can show cache counters, but that does not by itself prove Cowork's
  stock default.

## Reproduction

Run the check from the Claude Desktop **Code** surface on a clean desktop
install. Do not infer from docs or memory; inspect local artifacts.
Sanitize all output to avoid printing secrets or prompt contents.

```bash
uname -a
sw_vers
which claude || true
claude --version || true
plutil -p /Applications/Claude.app/Contents/Info.plist \
  | egrep 'CFBundleIdentifier|CFBundleShortVersionString|CFBundleVersion' || true
ps auxww | egrep -i 'Claude|cowork|claude-code' | grep -v egrep || true

env | cut -d= -f1 \
  | egrep '^(ANTHROPIC_|CLAUDE_|ENABLE_PROMPT_CACHING|HTTP_PROXY|HTTPS_PROXY|ALL_PROXY|NO_PROXY)' || true
```

Then scan local Desktop/Code JSONL for numeric cache counters only:

```bash
python3 - <<'PY'
from pathlib import Path
import json
from collections import Counter

roots = [
    Path.home() / 'Library/Application Support/Claude',
    Path.home() / 'Library/Application Support/Claude-3p',
    Path.home() / '.claude',
]
summary = Counter()

def iter_usages(obj):
    if isinstance(obj, dict):
        if isinstance(obj.get('usage'), dict):
            yield obj['usage']
        if isinstance(obj.get('message'), dict) and isinstance(obj['message'].get('usage'), dict):
            yield obj['message']['usage']
        for value in obj.values():
            yield from iter_usages(value)
    elif isinstance(obj, list):
        for value in obj:
            yield from iter_usages(value)

for root in roots:
    if not root.exists():
        continue
    for fp in root.rglob('*.jsonl'):
        try:
            lines = fp.read_text(errors='replace').splitlines()
        except Exception:
            continue
        for line in lines:
            if 'cache_read_input_tokens' not in line and 'cache_creation_input_tokens' not in line:
                continue
            try:
                obj = json.loads(line)
            except Exception:
                continue
            for usage in iter_usages(obj):
                create = int(usage.get('cache_creation_input_tokens') or 0)
                read = int(usage.get('cache_read_input_tokens') or 0)
                if create or read:
                    summary['events_with_cache'] += 1
                    summary['cache_creation_input_tokens'] += create
                    summary['cache_read_input_tokens'] += read
                    creation = usage.get('cache_creation') or {}
                    if isinstance(creation, dict):
                        summary['ephemeral_1h_input_tokens'] += int(creation.get('ephemeral_1h_input_tokens') or 0)
                        summary['ephemeral_5m_input_tokens'] += int(creation.get('ephemeral_5m_input_tokens') or 0)

for key in sorted(summary):
    print(f'{key}={summary[key]}')
PY
```

Expected result for a working default Desktop Code session:

- `cache_creation_input_tokens > 0`
- `cache_read_input_tokens > 0`
